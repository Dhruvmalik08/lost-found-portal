# Lost & Found Portal

A web-based Lost and Found management system built as a college internal project.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Server: Apache (XAMPP)

## Features
- User registration and login with session management
- Post lost or found items with photo upload
- Browse and filter items by category, type, and status
- Claim system with accept/reject functionality
- Mark items as reunited
- Admin panel for managing users and items

## How to Run
1. Install XAMPP
2. Clone this repository into C:\xampp\htdocs\lost-found-portal
3. Import setup.sql into MySQL
4. Start Apache and MySQL in XAMPP
5. Visit http://localhost/lost-found-portal/index.php
